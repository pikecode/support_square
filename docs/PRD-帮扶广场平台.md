# PRD：帮扶广场平台

**版本：** v1.2
**日期：** 2026-07-03
**来源：** 基于《PRD-生活服务平台改new》删减改造

---

## 1. 产品概述

### 1.1 产品定位

轻量级帮扶互助平台，用户可发布求助内容、互赠爱心币，通过充值提升账号等级获得专属称号。

### 1.2 核心价值

- **求助者**：发帖公开求助，接收爱心币支持
- **帮扶者**：赠送爱心币，通过充值提升等级称号
- **平台**：提供轻量互助空间 + 资金流转能力

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| **普通用户** | 注册后可发帖、收发站内信、充值提现、赠送爱心币 |
| **平台运营** | 用户管理、帖子下架、账号处理 |

---

## 2. 功能模块

### 2.1 注册与登录

**功能点：**
- 邮箱 + 密码注册，密码无格式限制
- 注册直接登录，无需邮箱验证
- 登录：邮箱 + 密码
- 忘记密码：发送重置链接到邮箱（此处才需要邮箱验证）

---

### 2.2 充值

**功能点：**
- 充值入口：个人中心 → 我的钱包
- 支持支付方式：
  - 微信支付
  - 支付宝
  - 银联支付
  - 京东支付
  - 多多支付
  - 聚合支付
- 快捷金额：50 / 100 / 200 / 500，支持自定义金额
- 充值记录查询
- 充值后账号等级自动提升，解锁对应称号（见下方等级体系）

**账号等级与称号（按累计充值金额）：**

| 等级 | 累计充值 | 称号 |
|------|----------|------|
| Lv.1 | 0 元 | 新人 |
| Lv.2 | 100 元 | 热心人 |
| Lv.3 | 500 元 | 爱心使者 |
| Lv.4 | 2000 元 | 公益达人 |
| Lv.5 | 5000 元 | 帮扶之星 |
| Lv.6 | 10000 元 | 守护天使 |

---

### 2.3 提现

**功能点：**
- 提现入口：个人中心 → 我的钱包
- 绑定提现账户：支付宝 / 银行卡
- 输入提现金额，立即到账，无需审核
- 提现记录查询

---

### 2.4 站内信

**功能点：**
- 会话列表（按最新消息排序）
- 发送消息类型：
  - 文字
  - 表情（emoji）
  - 图片
  - 爱心币（直接在对话中转账）
- 未读消息红点提醒
- 消息已读/未读状态

---

### 2.5 帮扶广场

**功能描述：** 用户发布求助文字，所有人可浏览，登录用户可赠送爱心币。

#### 2.5.1 发布帖子

**功能点：**
- 登录后点击"发布"
- 输入文字内容（必填，限 500 字）
- 发布后立即出现在广场列表
- 每个用户每天最多发布 10 条帖子

#### 2.5.2 广场展示

**功能点：**
- 按发布时间倒序展示（最新在最前）
- 每条帖子显示：发布者头像、昵称、等级称号、发布时间、内容、已获爱心币数量
- 未登录用户可浏览，登录后才能发帖/赠币
- 列表分页加载（每页 20 条）

#### 2.5.3 搜索

**功能点：**
- 搜索框支持：
  - 按昵称搜索用户发布的帖子
  - 按帖子内容关键词搜索
- 搜索结果按发布时间倒序排列

#### 2.5.4 赠送爱心币

**功能点：**
- 每条帖子下方有"赠送爱心币"按钮（登录后可见）
- 点击后输入赠送数量，确认后从余额扣除，直接到达发帖者账户
- 帖子卡片显示该帖已累计获得的爱心币总量
- 赠送记录可在个人中心查看

#### 2.5.5 帖子管理

**功能点：**
- 发布者可删除自己的帖子
- 平台运营可在后台下架任意帖子

## 3. 信息架构

```
首页（帮扶广场）
├── 搜索框（昵称 / 内容）
├── 帖子列表
│   └── 帖子卡片：头像 / 昵称 / 称号 / 时间 / 内容 / 爱心币数
│       └── 赠送爱心币按钮（登录后可见）
└── 发布入口（登录后可用）

个人中心
├── 我的资料（昵称 / 头像 / 等级称号）
├── 我的帖子
├── 我的钱包
│   ├── 余额 + 爱心币余额
│   ├── 充值
│   ├── 提现
│   └── 交易记录
└── 站内信
    ├── 会话列表
    └── 聊天（文字 / 表情 / 图片 / 爱心币）
```

---

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| 注册 | 同一邮箱不可重复注册 |
| 充值 | 支付回调幂等，掉单自动补单 |
| 提现 | 余额充足即可提现，实时到账 |
| 站内信 | 实时送达（WebSocket），图片限 10MB |
| 帮扶广场 | 每用户每天发帖上限 10 条，超出提示限制 |
| 爱心币 | 赠送操作原子性，防止双扣 |

---

## 5. 数据模型（核心字段）

| 实体 | 主要字段 |
|------|----------|
| User | id, email, password, nickname, avatar, level, balance, created_at |
| Post | id, user_id, content, heart_coins_total, created_at |
| Message | id, from_user, to_user, type(text/emoji/image/coin), content, created_at |
| Transaction | id, user_id, type(recharge/withdraw/send_coin/receive_coin), amount, created_at |

---

## 6. MVP 范围

**第一阶段（MVP）：**
- 注册 / 登录 / 忘记密码
- 充值（全支付方式）+ 等级称号
- 提现（即时）
- 站内信（文字 + 表情 + 图片 + 爱心币）
- 帮扶广场（发帖 / 浏览 / 搜索 / 赠送爱心币 / 删帖）

**第二阶段：**
- 等级勋章展示页
- 爱心币排行榜（获得最多 / 赠出最多）
- 推送通知（收到爱心币 / 站内信）
