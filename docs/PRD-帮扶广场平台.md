# PRD：帮扶广场平台

**版本：** v1.0
**日期：** 2026-07-02
**来源：** 基于《PRD-生活服务平台改new》删减改造

---

## 1. 产品概述

### 1.1 产品定位

一个轻量级的帮扶主题服务平台，聚焦核心交易能力 + 社交化帮扶功能。

### 1.2 核心价值

- **求助者**：发布帮扶需求，获得他人帮助
- **帮扶者**：认领帮扶任务，积累信用和回报
- **平台**：撮合帮扶供需，维持信任体系

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| **普通用户** | 可发布求助、认领帮扶、收发站内信 |
| **帮扶者** | 认领并完成帮扶任务，获得平台积分/奖励 |
| **平台运营** | 审核帮扶内容、处理纠纷、管理用户 |

## 2. 功能模块

### 2.1 注册

**功能描述：** 用户注册成为平台成员。

**功能点：**
- 手机号注册（验证码）
- 微信/支付宝第三方登录
- 基础信息填写：昵称、头像、简介
- 用户类型选择：普通用户 / 帮扶者
- 帮扶者需补充：帮扶领域、可提供服务、资质证明（可选）
- 注册即送初始帮扶积分

### 2.2 充值

**功能描述：** 用户向平台账户充值余额。

**功能点：**
- 充值入口：个人中心 → 我的钱包
- 充值方式：微信支付、支付宝、银行卡
- 支持自定义金额 + 快捷金额选项（50/100/200/500）
- 充值记录查询
- 充值成功后平台赠送等额帮扶积分（1元 = 1积分）

### 2.3 提现

**功能描述：** 用户将平台余额提现到外部账户。

**功能点：**
- 提现入口：个人中心 → 我的钱包
- 最低提现金额限制（如 10 元）
- 绑定提现账户：银行卡、支付宝
- 提现手续费说明
- 提现审核（平台运营审核后放款）
- 提现记录与状态跟踪（审核中 / 已到账 / 驳回）

### 2.4 站内信

**功能描述：** 用户之间的私信沟通工具。

**功能点：**
- 发送站内信（支持文字）
- 会话列表
- 未读消息提醒（红点 + 数字）
- 消息已读/未读状态
- 消息通知（系统通知 + 用户消息分开）
- 敏感词过滤

### 2.5 帮扶广场

**功能描述：** 核心特色功能，用户发布和认领帮扶需求的社会化互助空间。

#### 2.5.1 求助发布

**功能点：**
- 发帖入口：帮扶广场 → 发布求助
- 填写内容：
  - 求助标题（必填，限 30 字）
  - 求助描述（必填，限 500 字）
  - 求助分类（助学 / 医疗 / 就业 / 生活 / 其他）
  - 帮扶形式（物资 / 技能 / 劳动力 / 资金）
  - 预算/报酬（可选，可设置为纯公益）
  - 期望完成时间
  - 所在地区
  - 图片（最多 9 张）
  - 联系方式可见性（公开 / 仅帮扶者可见）
- 发布后进入审核队列
- 审核通过后在广场展示

#### 2.5.2 广场展示

**功能点：**
- 信息流列表：
  - 卡片展示：标题、分类、帮扶形式、预算/公益标签、发布时间、距离
  - 图片缩略图
  - 帮扶者认领数 / 需要人数
- 筛选与排序：
  - 按分类筛选（助学 / 医疗 / 就业 / 生活 / 其他）
  - 按帮扶形式筛选
  - 按地区筛选
  - 按发布时间排序 / 按热度排序 / 按距离排序
- 搜索：关键词搜索求助标题和描述
- 推荐：首页推荐优质帮扶需求

#### 2.5.3 帮扶认领

**功能点：**
- 帮扶者点击"我要帮扶"
- 填写帮扶方案（帮扶者说明如何帮助）
- 求助者审核帮扶方案
- 审核通过 → 进入帮扶执行阶段
- 审核驳回 → 帮扶者可重新提交方案
- 认领后状态变化：待审核 → 帮扶中 → 已完成

#### 2.5.4 帮扶执行与验收

**功能点：**
- 任务执行中：帮扶者和求助者可通过站内信沟通
- 求助者确认完成/验收
- 帮扶者也可申请完成，等待求助者确认
- 超时未确认 → 默认完成（如 7 天）

#### 2.5.5 帮扶评价

**功能点：**
- 双方互评
- 评价维度：态度、效率、结果满意度（1-5 星）
- 评价文字描述
- 评价后展示在帮扶者/求助者的个人主页
- 差评处理：可申诉

#### 2.5.6 帮扶积分与等级

**功能点：**
- 帮扶积分获取方式：
  - 完成帮扶任务（+5~50 积分）
  - 充值赠送（1 元 = 1 积分）
  - 平台奖励（优质帮扶额外奖励）
- 帮扶等级：
  - 青铜 / 白银 / 黄金 / 钻石（按累计积分划分）
  - 等级特权：优先推荐、免审发布、专属标识
- 积分排行榜（周榜 / 月榜 / 总榜）

#### 2.5.7 举报与审核

**功能点：**
- 用户可举报虚假求助/不当内容
- 平台运营审核：
  - 求助内容审核（发布前）
  - 纠纷处理
  - 违规处罚（封号、扣积分）
- 审核后台：待审列表、已审列表、举报处理


## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| 注册 | 手机验证码 60s 有效期，防刷 |
| 充值 | 支付回调幂等，掉单自动补单 |
| 提现 | 人工审核 + 风控规则 |
| 站内信 | 实时送达（WebSocket/轮询），消息存储 6 个月 |
| 帮扶广场 | 列表分页，图片压缩，敏感词过滤 |
| 积分 | 防刷机制，每日获取上限 |

## 5. 商业模式（轻量）

- **资金沉淀**：充值余额在提现前产生资金沉淀
- **提现手续费**：收取小额手续费（如 0.5%）
- **增值服务**：帮扶任务置顶、加急审核（未来扩展）
- **公益合作**：与企业/公益组织合作，赞助帮扶积分

## 6. MVP 范围

**第一阶段（MVP）：**
- 注册（手机号 + 第三方登录）
- 充值（微信 + 支付宝）
- 提现（人工审核）
- 站内信（基础文本聊天）
- 帮扶广场（发布求助 + 认领 + 评价 + 积分）

**第二阶段：**
- 帮扶等级与排行榜
- 图片上传
- 分类/地区筛选
- 举报审核系统

**第三阶段：**
- 帮扶方案多人竞标
- 物资流转追踪
- 公益组织合作接入
