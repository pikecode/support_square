# PRD：帮扶广场平台

**版本：** v1.1
**日期：** 2026-07-03
**来源：** 基于《PRD-生活服务平台改new》删减改造

---

## 1. 产品概述

### 1.1 产品定位

一个轻量级的帮扶主题服务平台，聚焦核心交易能力 + 社交化帮扶功能。

### 1.2 核心价值

- **求助者**：发布帮扶需求，获得他人帮助
- **帮扶者**：认领帮扶任务，积累信用和回报
- **平台**：撮合帮扶供需，维持信任体系

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| **普通用户** | 可发布求助、认领帮扶、收发站内信 |
| **帮扶者** | 认领并完成帮扶任务，获得平台积分/奖励 |
| **平台运营** | 审核帮扶内容、处理纠纷、管理用户 |

## 2. 功能模块

### 2.1 注册

**功能描述：** 用户通过邮箱注册成为平台成员。

**功能点：**
- 填写邮箱 + 设置密码（密码最少 8 位）
- 发送邮箱验证链接，点击激活账号
- 登录：邮箱 + 密码
- 忘记密码：邮箱重置密码链接

### 2.2 充值

**功能描述：** 用户向平台账户充值余额。

**功能点：**
- 充值入口：个人中心 → 我的钱包
- 充值方式：微信支付、支付宝、银行卡
- 支持自定义金额 + 快捷金额选项（50/100/200/500）
- 充值记录查询
- 充值成功后平台赠送等额帮扶积分（1元 = 1积分）

### 2.3 提现

**功能描述：** 用户将平台余额提现到外部账户。

**功能点：**
- 提现入口：个人中心 → 我的钱包
- 最低提现金额限制（如 10 元）
- 绑定提现账户：银行卡、支付宝
- 提现手续费说明
- 提现审核（平台运营审核后放款）
- 提现记录与状态跟踪（审核中 / 已到账 / 驳回）

### 2.4 站内信

**功能描述：** 用户之间的私信沟通工具。

**功能点：**
- 发送站内信（支持文字）
- 会话列表
- 未读消息提醒（红点 + 数字）
- 消息已读/未读状态
- 消息通知（系统通知 + 用户消息分开）
- 敏感词过滤

### 2.5 帮扶广场

**功能描述：** 用户发布求助文字，所有人均可查看的公开互助信息流。

#### 2.5.1 发布帖子

**功能点：**
- 登录后进入帮扶广场，点击"发布"
- 输入一段文字描述求助内容（必填，限 500 字）
- 点击发布，帖子立即出现在广场列表

#### 2.5.2 广场展示

**功能点：**
- 按发布时间倒序展示所有帖子（最新在最前）
- 每条帖子显示：发布者昵称、发布时间、帖子内容
- 未登录用户也可浏览所有帖子
- 列表分页加载（每页 20 条）

#### 2.5.3 帖子管理

**功能点：**
- 发布者可删除自己的帖子
- 用户可举报不当内容
- 平台运营可下架违规帖子

## 3. 信息架构

```
首页（帮扶广场）
├── 帖子列表（所有人可见）
│   └── 帖子卡片：昵称 / 时间 / 内容
└── 发布入口（登录后可用）
    └── 文字输入框 → 发布

个人中心（登录后）
├── 我的帖子（已发布列表）
├── 我的钱包
│   ├── 余额
│   ├── 充值
│   ├── 提现
│   └── 交易记录
└── 站内信
    ├── 会话列表
    └── 聊天
```

---

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| 注册 | 邮箱验证链接 24h 有效，防重复注册同一邮箱 |
| 充值 | 支付回调幂等，掉单自动补单 |
| 提现 | 人工审核 + 风控规则 |
| 站内信 | 实时送达（WebSocket/轮询），消息存储 6 个月 |
| 帮扶广场 | 列表分页（每页 20 条），敏感词过滤，内容限 500 字 |

---

## 5. 商业模式（轻量）

- **资金沉淀**：充值余额在提现前产生资金沉淀
- **提现手续费**：收取小额手续费（如 0.5%）
- **增值服务**：帮扶任务置顶、加急审核（未来扩展）
- **公益合作**：与企业/公益组织合作，赞助帮扶积分

---

## 6. MVP 范围

**第一阶段（MVP）：**
- 注册（邮箱注册 + 登录 + 忘记密码）
- 充值（微信 + 支付宝）
- 提现（人工审核）
- 站内信（基础文本聊天）
- 帮扶广场（发布文字帖子 + 公开浏览 + 删除自己的帖子）

**第二阶段：**
- 举报与内容审核
- 搜索帖子
- 帖子评论/回复

**第三阶段：**
- 帮扶积分与等级体系
- 公益组织合作接入
